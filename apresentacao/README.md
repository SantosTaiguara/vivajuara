# Apresentação Viva Juara · House 7 Imóveis

Versão em código do artefato de slides (17 slides, 1920×1080), publicada pela Vercel em `/apresentacao/`.

- `index.html`: os slides, um `<section>` por slide, com os estilos no próprio elemento. Para mudar um texto, edite aqui.
- `deck.css` e `deck.js`: escala para a tela, navegação (setas, espaço, toque, clique), tela cheia e impressão (Ctrl+P gera um PDF com um slide por página).
- `img/`: perspectivas oficiais, planta, mapa, vista aérea e logo, em WebP.

As notas do apresentador ficaram de fora porque o site é público. Abrir um slide direto: `/apresentacao/#5`.
